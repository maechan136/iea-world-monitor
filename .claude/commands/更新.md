CLAUDE.mdの指示に従い、以下の手順を順番に実行してください。

1. ウェブ検索で本日のエネルギー市場データ（Brent/WTI原油、TTF、JKM、ホルムズ状況）と各国情勢を収集する
2. 収集データを data/latest.json に保存する（updated_at は現在時刻のJST）
3. `node update.js` を実行して index.html を生成する
4. `git add data/latest.json index.html && git commit -m "Daily update: $(date '+%Y-%m-%d')" && git push origin main` を実行する
5. 以下のコマンドでNetlifyにデプロイする：
   `netlify deploy --prod --dir . --site $NETLIFY_SITE_ID --auth $NETLIFY_AUTH_TOKEN --message "Daily update $(date +'%Y-%m-%d')"`
